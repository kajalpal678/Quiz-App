🎯 Quiz App

📌 About the Project

Quiz App is an interactive web application developed using HTML, CSS, and JavaScript. It allows users to answer quiz questions and test their knowledge through a simple and user-friendly interface.

✨ Features

- Interactive multiple-choice questions.
- Easy-to-use interface.
- Displays quiz questions and answer options.
- Tracks the user's score.
- Shows results after completing the quiz.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the "index.html" file in your web browser.

🎯 Project Objective

The objective of this project is to practice front-end web development skills and learn how to create an interactive quiz application using HTML, CSS, and JavaScript.
